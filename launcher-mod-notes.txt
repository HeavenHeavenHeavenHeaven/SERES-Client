26.10.14 패치노트 · 런처·모드
■ 런처 1.0.7 업데이트

• 화면 크기 및 UI 배율 개선
- 런처 창 크기를 자유롭게 조절할 수 있습니다.
- 해상도와 Windows 배율에 맞춰 UI 크기가 자동으로 조절됩니다.
- 실행 옵션에서 UI 배율을 직접 선택할 수 있습니다.
- 작은 화면에서 글씨나 버튼이 겹치거나 화면 밖으로 나가는 문제를 개선했습니다.

• 모드 켜기·끄기
- 모드 목록의 스위치로 원하는 모드를 켜고 끌 수 있습니다.
- 끈 모드는 삭제하지 않고 보관하며, 다시 켜서 사용할 수 있습니다.
- 직접 추가한 모드도 ‘개인’ 탭에서 관리할 수 있습니다.
- 목록 모드를 변경한 뒤에는 ‘적용’을 눌러 주세요.

• 쉐이더 지원
- 모드 목록에 Iris를 추가했습니다.
- 호환되는 쉐이더팩을 적용할 수 있습니다.

• 업데이트 확인 통합
- 하단 ‘업데이트 확인’에서 런처·모드·리소스팩 업데이트를 함께 확인합니다.
- 새 런처 버전이 있으면 설치를 진행할 수 있습니다.
- 게임 버전 아래에 현재 런처 버전을 표시합니다.

• 런처·모드 소식 추가
- 패치노트 아래에 ‘런처·모드 소식’ 메뉴를 추가했습니다.
- 서버 패치노트와 런처·모드 업데이트 내역을 따로 확인할 수 있습니다.

• 기타 수정
- 다른 창을 클릭할 때 런처 테두리가 하얗게 깜빡이던 문제를 개선했습니다.
- 설치 시 바탕화면에 런처 바로가기가 생성되도록 보완했습니다.
- 기존 배포 서명 시스템을 제거했습니다. 다운로드 주소 및 파일 해시 검증은 유지됩니다.
