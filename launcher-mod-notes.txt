# 모드 업데이트 
- SERES Core Guide 세레스 코어 도감 모드 추가했습니다.


## SERES Core Guide 사용법

채팅에 `/코어검색`을 입력하면 모드가 열립니다. 상단에서 코어 검색, 합성 계산, 코어 도감 중 원하는 탭을 선택하세요.

## 코어 검색

- 검색창에 몬스터 이름이나 효과를 입력하세요. `슬라임 킹`을 검색하면 해당 몬스터의 코어가, `경험치 획득`을 검색하면 경험치 보너스가 있는 코어가 나옵니다.
- 지역·무기·능력치 필터를 함께 사용하면 검색 결과를 좁힐 수 있습니다.
- 코어에 마우스를 올리면 효과와 수치를 볼 수 있습니다. 클릭하면 상세 정보와 즐겨찾기 버튼이 나타납니다. 휠을 돌리는 동안에는 정보창이 잠시 숨고, 멈추면 다시 표시됩니다.

## 코어 도감 — 내게 필요한 코어 확인하기

1. 채팅에 `/도감`을 입력해 서버 도감을 엽니다.
2. 확인할 층이나 무법의 섬을 선택한 뒤 몬스터 목록 페이지를 차례로 넘겨보세요. 모드는 직접 열어 본 페이지의 등록 상태를 저장합니다.
3. `/코어검색`을 입력하고 코어 도감 탭에서 지역을 선택하세요. 몬스터별로 필요한 코어만 확인할 수 있습니다. 목록을 복사하려면 층별 복사 또는 전체 복사를 누르세요.

**미확인**은 모드가 아직 해당 칸의 등록 여부를 읽지 못했다는 뜻입니다. 미확인 칸이 있거나 새 코어를 등록했다면 `/도감`에서 해당 몬스터의 목록 페이지를 다시 열어 주세요.

## 합성 계산

- 합성 계산 탭에서 목표 레벨을 입력하고 조합 찾기를 누르면 코어 3개로 만들 수 있는 조합을 확인할 수 있습니다.
- 보스 재료를 사용할지 선택하거나 꼭 포함할 재료 레벨을 지정하면, 해당 조건에 맞는 조합만 표시됩니다
